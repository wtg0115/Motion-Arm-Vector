## 2. 산술 검산 결과 (deg ↔ pulse ↔ us 일관성)

- PCA9685 @ 50Hz: prescale=131, 실제 49.938Hz, **1count ≈ 4.889us**
- 펄스 창: 500us=102.27count, 2500us=511.36count (전 채널 공통)
- 변환식: `count = 102.27 + (angle/RANGE) × 409.09`
- **검산: 15개 점 전부 최대오차 0.04count / 0.6us → 오타 없음 ✅**
- 참조자세 역검증: 사람 45° → CH2 매핑 134.5° vs 실제 135.0° (오차 0.5°, 일치)

## 5. 전원 (중요 — 사망 원인 기록)

| 구성 | 전압 | 결과 |
|---|---|---|
| 2셀(2S) 18650 | 8.4V (만충) | ❌ DS3218 상한 6.8V 초과 → 미작동(보호 컷). **최초 미작동 근본원인** |
| 1셀(1S) 18650 | 3.7~4.2V | ✅ 작동 (정격 4.8V보다 약간 낮아 CH1 토크 부족하나 구동됨) |
| 정격 권장 | 4.8~6.8V (벅 6.0V) | (미보유) 이상적. 벅 컨버터 6V가 정석 |

- DS3218 정격: **4.8~6.8V** (상한 6.8V)
- ⚠️ 110V→220V 변환기 오사용으로 PCA9685 연기 → **해당 칩 폐기, 신품 교체 완료**
