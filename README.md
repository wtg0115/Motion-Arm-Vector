# Arm Vector — 팔 따라 움직이는 로봇팔

휴대폰·태블릿 카메라로 사람 팔의 관절 위치를 읽어 벡터로 바꾸고, 그 각도를 아두이노 서보로 보내 로봇팔이 사람 팔을 따라 움직이게 하는 프로젝트예요.
카메라 인식과 계산은 브라우저 하나로 돌아가고, 따로 설치할 것이 없어요. 로봇 쪽은 `arduino/` 폴더의 펌웨어를 올려 써요.

- **최신 버전 바로 쓰기:** https://wtg0115.github.io/Motion-Arm-Vector/
- **모든 버전 모아 보기:** https://wtg0115.github.io/Motion-Arm-Vector/versions/

## 어떻게 돌아가나

1. **인식** — MediaPipe(자세·손 인식 모델)가 카메라 화면에서 어깨·팔꿈치·손목·손가락 위치를 찾아요.
2. **계산** — 관절 위치를 벡터로 바꾸고, 내적으로 관절 각도를 구해요. 손목 회전은 쿼터니언으로 다뤄요.
3. **다듬기** — One Euro 필터로 떨림을 줄이고, 기준자세를 등록해 사람마다 다른 팔 길이·가동범위를 맞춰요.
4. **제어** — 브라우저에서 아두이노로 바로 연결(Web Serial, 115200bps)해 서보 각도를 보내요. 아두이노는 PCA9685 서보 드라이버로 서보를 움직여요.

| 채널 | 관절 | 서보 |
|---|---|---|
| CH0 | 베이스 회전 | 25kg, 280° |
| CH1 | 숄더(어깨) | 35kg, 280° |
| CH2 | 엘보우(팔꿈치) | 20kg, 180° |
| CH3 | 손목 상하 | 20kg, 180° |
| CH4 | 손목 축회전 | 20kg, 180° |

### 알아 둘 점
- **v10.3(데모 조정·최종)과 짝인 펌웨어 v7.4는 지금 남아 있지 않아요.** 컴퓨터의 `arm_firmware_v7_4_demo_tuned.ino` 파일 내용이 나중에 EMG 측정용 코드로 덮어써졌어요. v10.3 화면을 v7.3 펌웨어와 쓰면 펌웨어가 ±10° 제한으로 막아서 로봇이 덜 움직이고 CH4는 고정돼요(위험한 쪽은 아님). 데모 범위로 쓰려면 v7.3의 `FIRST_LIVE_TEST_DELTA`를 `{25, 20, 25, 20, 82}`로 바꾼 v7.4를 다시 만들어야 해요.
- **Multi v4**는 작업 스레드를 모듈 방식으로 띄우는 판이에요. 예전에 이 방식에서 `ModuleFactory not set` 오류가 났고 v4.1에서 고쳤는데, v4.1 파일은 남아 있지 않아요.
- v1 화면(한 사람만 인식하던 첫 판), Python 버전(`arm_vector_camera.py`), v4.1 펌웨어와 같이 쓰던 수동 조종기 HTML은 남아 있지 않아요.

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 최신 화면(v10.3 최종). 사이트 주소로 열리는 파일 |
| `versions/` | 모든 화면 버전 모음. `versions/index.html`은 버전 목록 페이지 |
| `arduino/` | 펌웨어 버전 모음 |

화면은 모두 파일 하나로 돌아가요. 카메라를 쓰기 때문에 파일을 직접 열면(file://) 막히니, 꼭 위 웹 주소로 여세요.
