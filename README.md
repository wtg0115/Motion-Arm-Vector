# Arm Vector — 팔 따라 움직이는 로봇팔

휴대폰·태블릿 카메라로 사람 팔의 관절 위치를 읽어 벡터로 바꾸고, 그 각도를 아두이노 서보로 보내 로봇팔이 사람 팔을 따라 움직이게 하는 프로젝트예요.
카메라 인식과 계산은 브라우저 하나로 돌아가고, 따로 설치할 것이 없어요.

- **최신 버전 바로 쓰기:** https://wtg0115.github.io/Motion-Arm-Vector/
- **모든 버전 모아 보기:** https://wtg0115.github.io/Motion-Arm-Vector/versions/

## 어떻게 돌아가나

1. **인식** — MediaPipe(자세·손 인식 모델)가 카메라 화면에서 어깨·팔꿈치·손목·손가락 위치를 찾아요.
2. **계산** — 관절 위치를 벡터로 바꾸고, 내적으로 관절 각도를 구해요. 손목 회전은 쿼터니언으로 다뤄요.
3. **다듬기** — One Euro 필터로 떨림을 줄이고, 기준자세를 등록해 사람마다 다른 팔 길이·가동범위를 맞춰요.
4. **제어** — 브라우저에서 아두이노로 바로 연결(Web Serial)해 서보 각도를 보내요.

| 채널 | 관절 |
|---|---|
| CH0 | 베이스 |
| CH1 | 숄더(어깨) |
| CH2 | 엘보우(팔꿈치) |
| CH3 | 손목 상하 |
| CH4 | 손목 축회전 |

### 버전마다 알아 둘 점
- **v10.1** 파일 안에는 v10.3이라고 표시된 수정 두 가지도 들어 있어요. 손목 축회전(CH4)을 기본 범위 ±80°로 먼저 움직이게 한 것과, 시작 자세 일치 기준을 조금 느슨하게 한 것이에요.
- **Multi v4**는 작업 스레드를 모듈 방식으로 띄우는 판이에요. 예전에 이 방식에서 `ModuleFactory not set` 오류가 났고 v4.1에서 고쳤는데, v4.1 파일은 GitHub에 올라온 적이 없어요.
- v1·v2(첫 단일 인물 판, 여러 사람 판)와 Python 버전(`arm_vector_camera.py`)도 GitHub에 없어요.
- **아직 안 올라온 것:** 화면 쪽 v10.2~v10.4와 아두이노 펌웨어(v7.3). 펌웨어는 115200bps로 `STATE,` · `ERR,` 형식의 메시지를 주고받는 판이어야 v10.x와 맞아요. 올리면 `versions/`와 `arduino/` 폴더에 넣으면 돼요. (6월에 만든 `arm_servo_receiver.ino`는 서보 2개용 `S95,E60` 형식이라 v10.x와 맞지 않아요.)

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 최신 버전(v10.1). 사이트 주소로 열리는 파일 |
| `versions/` | 모든 버전 모음. `versions/index.html`은 버전 목록 페이지 |

모든 버전이 파일 하나로 돌아가요. 카메라를 쓰기 때문에 파일을 직접 열면(file://) 막히니, 꼭 위 웹 주소로 여세요.
